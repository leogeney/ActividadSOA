📋 Parcial I - Arquitectura Orientada a Servicios (SOA)

Este proyecto corresponde al desarrollo del Parcial I de la asignatura Arquitectura Orientada a Servicios, enfocado en la implementación de un sistema de autenticación con múltiples vistas.

🚀 Cómo Ejecutar el Proyecto

Sigue estos pasos para ejecutar la aplicación en tu entorno local:

# Clonar el repositorio
git clone https://github.com/leogney/ActividadSOA.git

# Acceder al directorio del proyecto
cd ActividadSOA

# Instalar dependencias
npm install

# Ejecutar la aplicación
npm run dev

Luego, abre tu navegador en:

👉 http://localhost:5173
